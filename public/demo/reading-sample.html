What is the DOM?

The Document Object Model (DOM) is a programming interface for HTML and XML documents. It represents the page so that programs can change the document structure, style, and content.

Common Operations

  • Selecting elements: using document.querySelector and document.getElementById.
  • Changing content: update textContent or innerHTML.
  • Event handling: attach listeners with addEventListener.
